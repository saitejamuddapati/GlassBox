# GlassBox: Explainable Credit Card Fraud Detection

**GlassBox** is an end-to-end, interpretable fraud detection platform engineered for high-stakes financial environments where trust and transparency are critical. Powered by extreme gradient boosting (XGBoost) and SHAP (SHapley Additive exPlanations), GlassBox accurately identifies fraudulent transactions from highly imbalanced payment data while providing real-time, human-understandable risk attributions through an intuitive web interface and high-performance FastAPI service.
